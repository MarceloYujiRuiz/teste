## 📖 Descrição do Projeto

Este projeto é um site informativo sobre o **ODS 2 — Fome Zero e Agricultura Sustentável**, um dos 17 Objetivos de Desenvolvimento Sustentável estabelecidos pela ONU com meta de cumprimento até 2030.

O site tem como propósito conscientizar a população sobre a realidade da fome e da insegurança alimentar no Brasil, apresentar as metas oficiais do ODS 2, indicar ações que qualquer cidadão pode tomar, e conectar visitantes a organizações parceiras que atuam no combate à fome. Conta ainda com uma página de cadastro para que pessoas interessadas possam se engajar com a causa.

O projeto foi desenvolvido para a disciplina de **Programação Web Front-End** da **UTFPR**, em 2026.

---

## ⚙️ Funcionalidades

- `Página inicial (index.html)`: apresenta seções informativas sobre o ODS 2, incluindo:
  - Descrição geral da iniciativa da ONU
  - As quatro principais metas do ODS 2 (2.1 a 2.4)
  - Dados sobre insegurança alimentar e agricultura familiar no Brasil
  - Lista de ações práticas para o cidadão contribuir
  - Links para parceiros e organizações relevantes (ONU, FAO, Banco de Alimentos, etc.)

- `Página de Cadastro e Login (cadastro.html)`: formulário para criação de conta com campos de nome, e-mail, telefone, data de nascimento, cidade, forma de contribuição e mensagem de motivação; e formulário de login com e-mail e senha.

- `Navegação`: menu fixo com links para todas as seções da página inicial e acesso direto à página de cadastro.

## 🌐 Como Acessar

O projeto é composto por arquivos estáticos e não requer nenhuma instalação ou servidor especial.

**Para rodar localmente:**

1. Clone ou baixe o repositório:
   ```bash
   git clone https://github.com/seu-usuario/fome-zero-ods2.git
   ```
2. Abra a pasta do projeto no seu explorador de arquivos.
3. Dê um duplo clique no arquivo `index.html` — ele abrirá diretamente no navegador.

> ⚠️ As imagens da pasta `figs/` são necessárias para a exibição correta do site. Certifique-se de que a pasta está presente junto aos arquivos HTML.

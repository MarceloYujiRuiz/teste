## Descrição do Projeto

Este projeto é um site que busca ajudar a **ODS 2 — Fome Zero e Agricultura Sustentável**, um dos 17 Objetivos de Desenvolvimento Sustentável estabelecidos pela ONU com meta de cumprimento até 2030.

O site tem como propósito conscientizar a população sobre a realidade da fome e da insegurança alimentar no Brasil, apresentar as metas oficiais do ODS 2, indicar ações que qualquer cidadão pode tomar, e conectar visitantes a organizações parceiras que atuam no combate à fome. 

O projeto foi desenvolvido para a disciplina de **Programação Web Front-End** da **UTFPR**, em 2026.

---

## Funcionalidades

- `Página inicial (index.html)`: apresenta seções informativas sobre o ODS 2, incluindo:
  - Descrição geral da iniciativa da ONU
  - As quatro principais metas do ODS 2 (2.1 a 2.4)
  - Dados sobre insegurança alimentar e agricultura familiar no Brasil
  - Lista de ações práticas para o cidadão contribuir
  - Links para parceiros e organizações relevantes

- `Página de Cadastro e Login (cadastro.html)`: formulário para criação de conta e login.

- `Navegação`: menu fixo com links para todas as seções da página inicial e à página de cadastro.
